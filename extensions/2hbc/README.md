# 2HBC — extension de test 0.1.0

Chargez ce dossier depuis chrome://extensions > Mode développeur > Charger l’extension non empaquetée.
Pour Edge : edge://extensions. Chrome de bureau est la cible des tests automatiques.

Cette version fournit un moteur de transfert par lot configurable. Les adaptateurs Rexel et Sonepar sont
désactivés par défaut jusqu’au repérage de leurs interfaces connectées. Ce n’est pas une intégration
fournisseur certifiée. Aucun POST vers une API privée n’est implémenté.

Connectez-vous directement chez le fournisseur. N’insérez jamais de mot de passe, cookie ou jeton dans
les réglages. Le premier essai utilise deux références réelles et s’arrête au panier.

Documentation : docs/AUTO_PANIER.md dans le dépôt mburgevin/2HBC, branche feat/auto-cart-prototype.
